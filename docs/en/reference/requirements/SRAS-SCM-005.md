# SRAS-SCM-005 — Licenses are identified, approved, and tracked for obligations

- Domain: `supply-chain`
- Criticality: `high`
- Status: `active`
- Introduced in: `0.2.0`
- Deprecated in: not deprecated
- Replaced by: none
- Review status: `draft`
- Translation status: `partial`
- Source: `core/domains/supply-chain.yaml`

## Description

Every third-party component must have a recorded license, an approval decision for its use, and a tracked obligation such as attribution or source disclosure. A component with an unapproved or unknown license fails the requirement.

**Thai:** องค์ประกอบจากบุคคลภายนอกทุกรายการต้องมี license ที่บันทึกไว้ การตัดสินใจอนุมัติการใช้งาน และข้อผูกพันที่ติดตาม เช่น การระบุที่มา หรือการเปิดเผย source องค์ประกอบที่มี license ที่ไม่อนุมัติหรือไม่ทราบถือว่าไม่ผ่านข้อกำหนดนี้
