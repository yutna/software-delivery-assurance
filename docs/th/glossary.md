# อภิธานศัพท์

คำศัพท์เดียวกันใช้ทั้งภาษาอังกฤษและภาษาไทย ส่วน identifier, schema key และ
ชื่อไฟล์คงเป็นภาษาอังกฤษ

## คำศัพท์หลัก

- **SRAS** — library ข้อกำหนดอ้างอิงใน repository นี้ เป็นชื่อผลิตภัณฑ์ ไม่ใช่
  เครื่องหมายรับรอง และไม่ใช่มาตรฐานที่เผยแพร่ คำสั่งและหน้าเอกสารอาจเรียกเนื้อหา
  นี้ว่า `standard content` ซึ่งเป็นคำเรียกสั้น ๆ ของเนื้อหาอ้างอิง ไม่ใช่มาตรฐาน
  ที่เผยแพร่
- **assurance** — การรับประกัน. งานที่อิงหลักฐานเพื่อแสดงว่า claim ของการส่งมอบ
  ได้รับการรองรับและข้อจำกัดมองเห็นได้
- **assessment** — การประเมิน. การประเมินข้อกำหนดที่ใช้ สถานะ ช่องว่าง และ
  หลักฐาน ณ เวลาหนึ่ง
- **evidence** — หลักฐาน. บันทึกที่รองรับข้อกำหนดหรือ claim พร้อม owner และ
  ขีดจำกัดความสด
- **evidence freshness** — ความสดของหลักฐาน. สถานะว่าหลักฐานยังอยู่ในอายุสูงสุด
  ณ วันที่ประเมินหรือไม่
- **gate** — เกต. ข้อกำหนดที่ต้องถึงระดับขั้นต่ำก่อนส่งมอบและยกเว้นไม่ได้
- **module** — โมดูล. ส่วนขยายทางเทคนิคที่เลือกได้ตามลักษณะผลิตภัณฑ์
- **overlay** — ส่วนเพิ่ม. ส่วนเพิ่มตามเขตอำนาจหรืออุตสาหกรรมที่เพิ่ม เข้มงวดขึ้น
  หรือยกเว้นข้อกำหนดที่ไม่ใช่ gate
- **register** — ทะเบียน. ดัชนีข้อเท็จจริงของกฎหมาย กฎระเบียบ มาตรฐาน หรือ
  แนวทาง พร้อมแหล่งอ้างอิงทางการ
- **claim** — ข้อกล่าวอ้าง. ถ้อยแถลงสาธารณะที่รองรับด้วยหลักฐาน พร้อมถ้อยคำที่
  อนุญาตและห้ามใช้
- **project instance** — อินสแตนซ์โปรเจกต์. repository ส่วนตัวหรือแยกต่างหากที่
  เก็บ scope, assessment, evidence index, claims และความเสี่ยง
- **lockfile** — ไฟล์ lock. `assurance.lock.yaml` ที่ pin input ที่ resolve แล้ว
  เวอร์ชัน และค่า SHA-256
- **resolution** — การ resolve. ชุดข้อกำหนดที่คำนวณจาก profile, tier, module และ
  overlay ของโปรเจกต์
- **profile** — โปรไฟล์. โหมดการประเมิน: `lite` หรือ `full`
- **tier** — ระดับ tier. ระดับความเสี่ยงของผลิตภัณฑ์ (1–3) ที่กำหนดว่าข้อกำหนด
  Core ข้อใดใช้
- **maturity** — ระดับ maturity. ความลึก L0–L4 ที่บันทึกในข้อกำหนดของ full
  profile
- **criticality** — ระดับความสำคัญ. น้ำหนักของข้อกำหนด: `gate`, `high`,
  `medium` หรือ `low`
- **finding** — ข้อค้นพบ. ช่องว่าง ข้อบกพร่อง หรือข้อสังเกตที่บันทึกโดยการ
  ประเมินหรือการตรวจทาน
- **remediation** — การแก้ไข. การกระทำที่ปิด finding พร้อม owner และ due date
- **risk acceptance** — การยอมรับความเสี่ยง. การตัดสินใจที่บันทึก มี owner และ
  มีกำหนดเวลา เพื่อยอมรับความเสี่ยงแทนการปิด

## คำที่ไม่ใช่คำพ้อง

- **register** ไม่ใช่ **overlay**
- **module** ไม่ใช่ **sector overlay**
- **assessment** ไม่ใช่ **certification**
- **claim** ไม่ใช่ **evidence**
- **gate** ยกเว้นไม่ได้
- **project instance** ไม่ใช่ repository สาธารณะนี้
- **SRAS reference library** ไม่ใช่ **published standard**
