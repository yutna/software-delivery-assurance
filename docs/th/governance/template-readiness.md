# ความพร้อมของ template

**เส้นทาง:** template / starter kit **สถานะ:** ใช้ได้โดยมีข้อจำกัด
**เนื้อหาเวอร์ชัน:** SRAS 0.9.0 **milestone การปรับตำแหน่ง:** v0.10.0
(ยังไม่ cut release และไม่ bump version) **บันทึกเมื่อ:** 2026-10-28

หน้านี้บอกว่าทีมใช้ส่วนใดได้จริงวันนี้ และต้องไม่กล่าวอ้างอะไร เป็นจุดเริ่มต้น
ของ template track ส่วน formal-standard track มี
[การทบทวนความพร้อม v1.0.0](v1-readiness.md) แยกต่างหาก

> หน้านี้เป็นฉบับภาษาไทยที่แปลโดยเครื่องและปรับถ้อยคำ ยังไม่ผ่านการตรวจทาน

## "ใช้ได้โดยมีข้อจำกัด" หมายถึงอะไร

starter kit เหมาะสำหรับการวางแผนภายใน การประเมินโปรเจกต์ การติดตามหลักฐาน
การจัดการช่องว่าง และการเตรียมบันทึก assurance ส่วนตัว แต่ไม่เหมาะเป็นฐานเดียว
สำหรับการตัดสินใจจัดซื้อ การรับรอง ข้อความว่าปฏิบัติตามกฎหมาย การอนุมัติเปิด
บริการต่อสาธารณะ หรือความเห็น assurance จากภายนอก

"ใช้ได้โดยมีข้อจำกัด" เป็นข้อความบอกตำแหน่งของสินค้า ไม่ใช่การรับรอง
ไม่ได้หมายความว่ามาตรฐาน stable แล้ว การแปลไทยสมบูรณ์แล้ว หรือผู้ตรวจทาน
ภายนอกอนุมัติเนื้อหาแล้ว

## พร้อมใช้ตอนนี้

| ความสามารถ                        | สถานะ  | สิ่งที่รองรับ                                                        |
| --------------------------------- | ------ | -------------------------------------------------------------------- |
| Clone, build และรันการตรวจ        | พร้อม  | CI และคำสั่งตรวจสอบใน README                                         |
| สร้าง instance แบบ lite หรือ full | พร้อม  | `sras init`, schema validation และ tests                             |
| ตรวจ instance ที่แก้ไขแล้ว        | พร้อม  | `sras project validate <dir>` อ่านอย่างเดียวและล้มเหลวเมื่อ lock ล้า |
| Refresh lockfile                  | พร้อม  | `sras project refresh <dir>` เขียนเฉพาะ lockfile                     |
| บันทึกหน่วยงานผู้ว่าจ้างภาครัฐ    | พร้อม  | `scope.public_sector` พร้อม contracting authority และ contract       |
| Core, module และ overlay          | มีอยู่ | ข้อกำหนด Core 70, module 52 และ overlay 45 ใน SRAS 0.9.0             |
| ทะเบียนและ crosswalk ไทย          | มีอยู่ | ทะเบียนไทย 12 รายการและ crosswalk 7 ชุด                              |
| Reference pages แบบ deterministic | พร้อม  | `sras render --check`                                                |
| Content guard สาธารณะ             | พร้อม  | `sras guard` และ CI annotations                                      |

## ข้อจำกัดที่ต้องวางแผนรับมือ

| ข้อจำกัด                            | ผลต่อโปรเจกต์                                                                          | สิ่งที่เจ้าของต้องทำ                                       |
| ----------------------------------- | -------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| การแปลไทยยัง partial                | ข้อกำหนด active 167 ข้อเป็น machine-assisted และยังไม่ผ่านมนุษย์                       | ใช้ภาษาอังกฤษเป็นฉบับหลัก และจัดผู้ตรวจทานไทยก่อนใช้ภายนอก |
| ทะเบียนยัง unverified               | รายการชี้แหล่งทางการแต่ไม่ใช่คำแนะนำทางกฎหมายหรือข้อสรุป compliance                    | ปรึกษาผู้เชี่ยวชาญกฎหมายหรือ regulatory focal point        |
| ยังไม่มีการทบทวนภายนอก              | ยังไม่มีผู้ตรวจทานอิสระตรวจมาตรฐานหรือ template                                        | ห้ามกล่าวอ้างการทบทวนภายนอกหรือการตรวจสอบอิสระ             |
| คำถามกฎหมายเปิดอยู่ 4 ข้อ           | ระยะเก็บรักษา การอนุมัติ cloud ของ ธปท. ระดับ WCAG และ licence open data ยังไม่มีคำตอบ | ตัดสินใจสำหรับโปรเจกต์และบันทึกคำตอบไว้ในที่ส่วนตัว        |
| ไม่มีการตรวจ evidence type coverage | gate อาจถูกทำเครื่องหมาย verified ด้วยเอกสารเดียว                                      | ตรวจชุดหลักฐานด้วยมนุษย์ก่อนลงนาม                          |
| CLI ยังไม่แสดง resolution output    | CLI ไม่พิมพ์ชุดข้อกำหนดและ gate ที่ resolve ทั้งหมด                                    | ใช้ reference ที่ generate และ lockfile ของโปรเจกต์        |
| ไม่มีรายการทะเบียน WCAG             | WCAG 2.2 ถูกอ้างโดย gate แต่ไม่มีในทะเบียน                                             | ถือเป็นการอ้างอิงเชิงข้อมูล ไม่ใช่ข้อสรุปทางกฎหมาย         |
| Template เป็นแบบกลาง                | ไม่มีกฎจัดซื้อ การเก็บรักษา หรือการอนุมัติเฉพาะหน่วยงาน                                | เพิ่มกฎเฉพาะใน instance ส่วนตัว ไม่ใช่ใน repository นี้    |

คำถามกฎหมายที่เปิดอยู่คือ `#128`, `#129`, `#130` และ `#131` finding ที่ยังเลื่อน
อยู่คือ `#126`, `#134` และ `#135` ส่วน finding ระดับ high `#127` และ `#132`
แก้แล้วโดย `#140` และ `#141`

## เงื่อนไขขั้นต่ำก่อนใช้งานจริง

1. มี executive sponsor ที่ระบุชื่อและยอมรับ scope กับความเสี่ยงคงเหลือ
2. กรอก [owner map](../templates/owner-map.md) ด้วยชื่อบทบาทจริง
3. project instance เป็นส่วนตัวและหลักฐานอยู่นอก repository นี้
4. มี legal หรือ regulatory focal point ตรวจทะเบียนและคำถามกฎหมายที่กระทบ
   โปรเจกต์
5. มีผู้ตรวจทานภาษาไทยที่เป็นมนุษย์ตรวจเนื้อหาภาษาไทยที่จะเผยแพร่หรือใช้ใน
   การตัดสินใจทางการ
6. ทีมบันทึก claims, ช่องว่าง, owner และ due date ไว้ใน instance ไม่ใช่เพียงใน
   บันทึกการประชุม

## เส้นทางการนำไปใช้

```text
อ่านหน้านี้
    -> มอบหมายเจ้าของ (owner map)
    -> สร้าง instance (quick start)
    -> กำหนด scope และ selection
    -> ประเมินและอ้างอิงหลักฐาน
    -> validate และ refresh lockfile
    -> ตรวจ claims และ risks
    -> ลงนามใน instance ส่วนตัว
```

template track จบที่การลงนามใน instance ส่วนตัว ไม่ได้ออกใบรับรองสาธารณะหรือ
การอนุมัติระดับมาตรฐาน

## เมื่อใดควรใช้ formal-standard track

ใช้ formal-standard track (ทางเลือก) เมื่อต้องการสิ่งใดสิ่งหนึ่งต่อไปนี้

- มาตรฐาน SRAS ที่ผ่านการทบทวน ไม่ใช่ starter kit
- บันทึกการทบทวนจากภายนอกที่เป็นอิสระ
- ข้ออ้างความเสถียรระดับ v1.0.0
- เนื้อหาภาษาไทยที่มนุษย์ตรวจครบทุกข้อกำหนด active
- ข้อความทางการว่าตัวมาตรฐาน (ไม่ใช่เพียงโปรเจกต์) ผ่านการทบทวนแล้ว

formal-standard track ยังไม่พร้อม [การทบทวนความพร้อม v1.0.0](v1-readiness.md)
ระบุ blockers ไว้ [External review packet](external-review-packet.md) และ
[Thai review kit](thai-review-kit.md) เป็นเครื่องมือทางเลือกของ track นี้
ไม่ใช่ข้อบังคับของ template track

  บันทึกข้อจำกัดเหล่านั้นไว้ใน risk register"

ห้ามใช้:

- "บริการของเราได้รับการรับรอง SRAS แล้ว หรือปฏิบัติตาม SRAS แล้ว"

- "การแปลภาษาไทยสมบูรณ์แล้ว"
- "template นี้รับประกันว่าจัดซื้อหรือเปิดบริการสาธารณะจะสำเร็จ"

## Confidence labels ในหน้านี้

- ข้อความเกี่ยวกับคำสั่งและจำนวนเป็น **checked** โดยคำสั่งตรวจสอบของ repository
  ให้รันใหม่ ณ commit ของคุณ จำนวนอาจเปลี่ยน
- คำอธิบายเนื้อหาเป็น **documented** จาก repository
- การตัดสินว่าหมาะสมเป็น **provisional** จนกว่าโปรเจกต์จริงจะใช้งาน
- งานปรับตำแหน่ง v0.10.0 เป็น **planned** และยังไม่ใช่ release

อ่าน [confidence labels](confidence-labels.md) สำหรับข้อตกลงนี้
