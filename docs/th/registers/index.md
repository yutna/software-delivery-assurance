# ทะเบียน

ทะเบียน (register) คือดัชนีข้อเท็จจริงของกฎหมาย กฎระเบียบ มาตรฐาน หรือแนวทาง
บันทึกแหล่งอ้างอิงทางการ วันที่ตรวจสอบ วันที่ครบกำหนดทบทวน และสถานะการตรวจทาน
ไม่ใช่ overlay ไม่ใช่คำแนะนำทางกฎหมาย และไม่ใช่ถ้อยแถลงว่าผลิตภัณฑ์ปฏิบัติตาม
เครื่องมือนั้น

## มาตรฐานภายนอกที่ข้อกำหนดอ้างอิง

ข้อกำหนดบางข้ออ้างมาตรฐานภายนอกที่สมัครใจเพื่อใช้เป็นแนวทางประเมิน ตัวอย่างเช่น
WCAG 2.2 สำหรับ accessibility (`TH-PUB-003` และ `TH-ECM-004`) และ NIST AI Risk
Management Framework 1.0 (`TH-FIN-010`) มาตรฐานเหล่านี้ไม่ใช่รายการทะเบียน

กฎคือ

- รายการทะเบียนมีไว้สำหรับกฎหมาย กฎระเบียบ หรือเครื่องมืออื่นที่มีเขตอำนาจ
  แหล่งอ้างอิงทางการ และวันครบกำหนดทบทวน
- มาตรฐานภายนอกที่สมัครใจอยู่ใน `references` ของข้อกำหนดพร้อมชื่อ URL และประเภท
  ไม่ใช่ overlay ไม่ใช่ข้อสรุปทางกฎหมาย และไม่ใช่ถ้อยแถลงว่าผลิตภัณฑ์สอดคล้อง
- ถ้ากฎหมายให้มาตรฐานมีผลผูกพันในเขตอำนาจใด ให้เพิ่มรายการทะเบียนสำหรับเครื่องมือ
  ที่ให้ผลผูกพันนั้นและ map ข้อกำหนดไปยังรายการนั้น
- โปรเจกต์บันทึกเวอร์ชันและเป้าหมาย conformance ที่เลือกไว้ใน assessment ของตนเอง
  อย่าถือว่าการที่มาตรฐานปรากฏในข้อกำหนดเป็นการพิสูจน์ความสอดคล้อง

แหล่งอ้างอิงทางการ:

- [WCAG 2.2](https://www.w3.org/TR/WCAG22/)
- [NIST AI Risk Management Framework 1.0](https://www.nist.gov/itl/ai-risk-management-framework)

## ข้อจำกัดในการตรวจทาน

ทะเบียนทุกรายการในรุ่นนี้เป็น `unverified` ยังไม่มีผู้ตรวจทานที่มีคุณสมบัติ
ลงนาม รายการเหล่านี้มีประโยชน์ในการค้นหาแหล่งอ้างอิงทางการและจัดโครงสร้างการ
ประเมิน แต่ไม่ใช่ข้อสรุปทางกฎหมาย

`review_status: reviewed` ต้องมีชื่อผู้ตรวจทาน วันที่ตรวจ และขอบเขต เนื้อหา
ทางกฎหมายยังคง unverified จนกว่าผู้ตรวจทานทางกฎหมายที่มีคุณสมบัติจะลงนาม
หากไม่มีผู้ตรวจทาน ข้อจำกัดยังคงมองเห็นได้ และรายการนั้นไม่ถูกใช้เป็นฐานของ
claim สาธารณะ

## ทะเบียนและ overlay

ทะเบียนบันทึกข้อเท็จจริง ส่วน overlay เพิ่มข้อกำหนด สองสิ่งนี้แยกจากกัน

- รายการทะเบียนไม่ได้เพิ่มข้อกำหนดด้วยตัวเอง
- overlay ไม่ได้ทวนกฎหมาย แต่ชี้ให้เห็นว่ารายการทะเบียนใดเกี่ยวข้อง
- ผลิตภัณฑ์ไม่ได้ถูกประเมินว่าปฏิบัติตามกฎหมายเพราะมีรายการทะเบียน

## เขตอำนาจอื่น

ประเทศไทย อาเซียน และสหภาพยุโรปมีทะเบียนที่ดูแลต่อเนื่องใน SRAS 1.1.0 รายการ
นอกประเทศไทยยังคงเป็นเพียงรายการอ้างอิงจนกว่าจะมีผู้ตรวจทานที่มีคุณสมบัติและ
บันทึกการตรวจทาน
