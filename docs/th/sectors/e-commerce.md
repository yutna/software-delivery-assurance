# อีคอมเมิร์ซ

overlay `TH-ECM` เพิ่มข้อกำหนด assurance 12 ข้อ สำหรับตลาดออนไลน์
แพลตฟอร์มขายตรงถึงผู้บริโภค checkout การชำระเงิน และซอฟต์แวร์จัดการคำสั่งซื้อ
ที่ดำเนินงานในประเทศไทย

## สิ่งที่ครอบคลุม

- ขอบเขตข้อมูลบัตรชำระเงินและ tokenisation
- การวางแผนและสื่อสารเมื่อ checkout ทำงานลดลง
- การป้องกันการเรียกเก็บซ้ำเมื่อ retry
- การเปลี่ยนแปลงคำสั่งซื้อ ราคา และโปรโมชันที่ตรวจสอบได้และย้อนกลับได้
- สถานะการคืนเงินและยกเลิกที่ตรงกันระหว่างระบบ
- การเปิดเผยข้อมูลผู้บริโภคและ consent ก่อนซื้อ
- การป้องกันการยึดบัญชีลูกค้า
- บันทึก consent การตลาดและการถอน consent
- การยืนยันตัวตน จำกัด และเพิกถอนสิทธิ์ partner API
- การเข้าถึงของ flow ที่ลูกค้าใช้ตามเป้าหมาย accessibility ที่ตกลง
- การเก็บรักษาและเรียกคืนบันทึกคำสั่งซื้อและข้อพิพาท
- การตอบสนองต่อการยึดบัญชีและการฉ้อโกงการชำระเงินที่ผ่านการทดสอบ

## ข้อกำหนด

- `TH-ECM-001` — ข้อมูลบัตรอยู่ในขอบเขตบัตรชำระเงินที่กำหนด
- `TH-ECM-002` — การทำงานลดลงของ checkout มีการวางแผนและสื่อสาร
- `TH-ECM-003` — checkout ที่ล้มเหลวไม่สร้างการเรียกเก็บซ้ำ
- `TH-ECM-004` — การเปลี่ยนแปลงคำสั่งซื้อ ราคา และโปรโมชันตรวจสอบได้และย้อนกลับได้
- `TH-ECM-005` — สถานะการคืนเงินและยกเลิกตรงกันระหว่างระบบ
- `TH-ECM-006` — การเปิดเผยข้อมูลผู้บริโภคและ consent แสดงก่อนซื้อ
- `TH-ECM-007` — บัญชีลูกค้าได้รับการป้องกันการยึดบัญชี
- `TH-ECM-008` — consent การตลาดถูกบันทึกและถอนได้
- `TH-ECM-009` — สิทธิ์ partner API มีการยืนยันตัวตน จำกัด และเพิกถอนได้
- `TH-ECM-010` — flow ที่ลูกค้าใช้เป็นไปตามเป้าหมาย accessibility ที่ตกลง
- `TH-ECM-011` — บันทึกคำสั่งซื้อและข้อพิพาทถูกเก็บและเรียกคืนได้
- `TH-ECM-012` — การยึดบัญชีและการฉ้อโกงการชำระเงินมีแนวตอบสนองที่ทดสอบแล้ว

ถ้อยแถลงเต็ม ความคาดหวังด้านหลักฐาน และแนวทางการประเมินอยู่ใน
[reference อีคอมเมิร์ซ](../../en/reference/overlays/TH-ECM.md) ที่ generate ไว้

## สิ่งที่ไม่ครอบคลุม

- ความเห็นเรื่องความชอบด้วยกฎหมายของข้อกำหนดผู้บริโภคหรือโฆษณา
- โปรแกรมรับรองบัตรชำระเงินเต็มรูปแบบ
- Due diligence ของผู้ขายในตลาดนอกเหนือจากข้อกำหนด partner API
- กฎภาษี ศุลกากร หรือการค้าข้ามพรมแดนสำหรับสินค้า
- การรับประกันว่า checkout จะเข้าถึงได้ ข้อกำหนดนี้ตั้งเป้าหมายที่ตกลงและ
  ความคาดหวังด้านหลักฐาน

## รายการทะเบียนที่เกี่ยวข้อง

overlay อีคอมเมิร์ซอ้างอิง `TH-ETA-001`, `TH-DPS-001`, `TH-CPA-001`,
`TH-PDPA-001`, `TH-PAY-001` และ `TH-BOT-002` อ่าน
[ดัชนีทะเบียน](../registers/index.md) สำหรับแหล่งอ้างอิงทางการและข้อจำกัดใน
การตรวจทาน
