# โลจิสติกส์

overlay `TH-LOG` เพิ่มข้อกำหนด assurance 11 ข้อ สำหรับระบบบริหารการขนส่ง
การจัดการคลังสินค้า การติดตาม การเชื่อมต่อศุลกากร และแพลตฟอร์มจัดส่งที่ดำเนินงาน
ในประเทศไทย

## สิ่งที่ครอบคลุม

- เหตุการณ์สถานะการจัดส่งที่มีเวลา เรียงลำดับ และกระทบยอดกัน
- การส่งต่อ chain-of-custody ที่บันทึกผู้ดำเนินการ สถานที่ และเวลา
- การตรวจจับและกระทบยอดความล้มเหลวของ EDI และ API
- การเข้าถึงคลังสินค้าและ depot ที่จำกัดขอบเขตและติดตาม
- การเข้าถึงของผู้ให้บริการขนส่งและผู้รับเหมาช่วงที่จำกัดและเพิกถอนได้
- กำลังรองรับช่วงพีคที่ทดสอบกับ forecast ที่ตกลง
- ความต่อเนื่องของการจัดเส้นทางและการจัดส่ง
- การแบ่งปันข้อมูลกับ partner อย่างจำกัดภายใต้ข้อตกลง
- ข้อมูลศุลกากรและการค้าที่ถูกต้องและตรวจสอบย้อนกลับได้
- การตอบสนองต่อการจัดส่งที่หาย ล่าช้า หรือส่งผิดเส้นทาง
- บันทึก proof-of-delivery ที่ตรวจจับการแก้ไขได้และเก็บรักษาไว้

## ข้อกำหนด

- `TH-LOG-001` — เหตุการณ์สถานะการจัดส่งมีเวลา เรียงลำดับ และกระทบยอดกัน
- `TH-LOG-002` — การส่งต่อ chain-of-custody บันทึกผู้ดำเนินการ สถานที่ และเวลา
- `TH-LOG-003` — ความล้มเหลวของ EDI และ API ถูกตรวจจับและกระทบยอดภายในกรอบเวลา
- `TH-LOG-004` — การเข้าถึงคลังสินค้าและ depot ถูกจำกัดและติดตาม
- `TH-LOG-005` — การเข้าถึงของผู้ให้บริการขนส่งและผู้รับเหมาช่วงถูกจำกัดและเพิกถอนได้
- `TH-LOG-006` — capacity ช่วงพีคถูกทดสอบกับ forecast ที่ตกลง
- `TH-LOG-007` — ความต่อเนื่องของการจัดเส้นทางและการจัดส่งมีแผนและผ่านการฝึกซ้อม
- `TH-LOG-008` — การแบ่งปันข้อมูล partner ถูกจำกัดและกำกับด้วยข้อตกลง
- `TH-LOG-009` — ข้อมูลศุลกากรและการค้าถูกต้องและตรวจสอบย้อนกลับได้
- `TH-LOG-010` — การจัดส่งที่หาย ล่าช้า หรือส่งผิดเส้นทางมีแนวตอบสนองที่ทดสอบแล้ว
- `TH-LOG-011` — บันทึก proof-of-delivery ตรวจจับการแก้ไขได้และเก็บรักษาไว้

ถ้อยแถลงเต็ม ความคาดหวังด้านหลักฐาน และแนวทางการประเมินอยู่ใน
[reference โลจิสติกส์](../../en/reference/overlays/TH-LOG.md) ที่ generate ไว้

## สิ่งที่ไม่ครอบคลุม

- การจำแนกประเภทศุลกากรหรือคำแนะนำเรื่องอากร
- ความเห็นทางกฎหมายเรื่องความรับผิดของผู้ให้บริการขนส่ง
- โปรแกรมศุลกากรหรือการค้าที่สมบูรณ์
- ความปลอดภัยทางกายภาพของคลังสินค้าเกินข้อกำหนดด้านการเข้าถึงและหลักฐาน
- การรับประกันว่าผู้ให้บริการขนส่งจะส่งตรงเวลา

## รายการทะเบียนที่เกี่ยวข้อง

overlay โลจิสติกส์อ้างอิง `TH-BOT-001`, `TH-CPA-001`, `TH-CYBER-001`,
`TH-ETA-001` และ `TH-PDPA-001` อ่าน
[ดัชนีทะเบียน](../registers/index.md) สำหรับแหล่งอ้างอิงทางการและข้อจำกัดใน
การตรวจทาน
