# ภาคธุรกิจ

overlay ภาคธุรกิจของประเทศไทยสี่ชุดเพิ่มข้อกำหนดบน SRAS Core แต่ละชุดเป็น
ส่วนเพิ่ม ไม่ได้ทำซ้ำ Core และไม่ได้แทนทะเบียน

- [การเงิน](finance.md) — `TH-FIN`, 10 ข้อกำหนด
- [อีคอมเมิร์ซ](e-commerce.md) — `TH-ECM`, 12 ข้อกำหนด
- [โลจิสติกส์](logistics.md) — `TH-LOG`, 11 ข้อกำหนด
- [ภาครัฐ](public-sector.md) — `TH-PUB`, 12 ข้อกำหนด

## วิธีใช้ overlay

1. เลือก overlay ใน `assurance.yaml` เมื่อผลิตภัณฑ์ดำเนินงานในภาคธุรกิจนั้น
   ในประเทศไทย
2. Resolve overlay บน Core และ module ที่เลือก
3. ประเมินทุกข้อกำหนดที่ใช้ รวมถึง gate ของ overlay
4. บันทึกเหตุผล `not_applicable` สำหรับข้อกำหนด overlay ที่ไม่ใช้ อย่าลบออก
5. เก็บการอ้างอิงทางกฎหมายที่เป็นข้อเท็จจริงไว้ใน
   [ทะเบียน](../registers/index.md) ไม่ใช่ใน overlay

## สิ่งที่ overlay ไม่ทำ

- ไม่ได้ระบุว่าผลิตภัณฑ์ปฏิบัติตามกฎหมาย
- ไม่ได้แทนการตรวจทานทางกฎหมาย
- ไม่ครอบคลุมภาคธุรกิจนอกสี่ชุดที่รองรับ
- ไม่ยกเว้น gate
- ไม่รับรองผู้ขายหรือผลิตภัณฑ์

overlay เป็นเนื้อหาฉบับร่าง ยังไม่มีผู้ตรวจทานที่มีคุณสมบัติลงนาม ใช้เพื่อ
จัดโครงสร้างการประเมิน ไม่ใช่ข้อสรุปทางกฎหมาย
