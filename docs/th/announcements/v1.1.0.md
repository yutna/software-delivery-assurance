# Announcement template v1.1.0

**สถานะ:** final สำหรับ template release v1.1.0 เมื่อ 2026-10-28
**เวอร์ชันเนื้อหา:** SRAS 1.1.0 **release:** template release v1.1.0

นี่คือ **template release** ไม่ใช่ standard release ส่วน announcement นี้ใช้ข้อความ
ที่ตรวจสอบได้จาก repository ไม่ระบุชื่อลูกค้า โปรเจกต์จริง ผู้ทบทวน วันที่ที่ยัง
ไม่เกิดขึ้น หรือ sign-off ที่ไม่มีอยู่

## ประกาศสั้น

> โครงการ Software Delivery Assurance เผยแพร่ template release 1.1.0 ของ
> SRAS starter kit ส่วน release นี้แสดง rationale, แนวทางการประเมิน, references
> และ crosswalk links บนหน้า requirement ที่สร้าง เพิ่ม crosswalk NIST SP 800-218
> (SSDF) แบบเจาะจง จัดทำเอกสารการตรวจสอบใน CI และการอัปเกรด 1.x สำหรับ adopter
> และทำให้ sign-off ที่ยังไม่ลงนามชัดเจนขึ้น ส่วน kit มี requirement ที่ใช้งานอยู่
> 167 ข้อ ครอบคลุม Core, module ทางเทคนิคห้าโมดูล และ overlay ประเทศไทยสี่ชุด
> พร้อมทะเบียนกฎระเบียบ 27 รายการ, crosswalk เชิงข้อมูล 8 ชุด, CLI สำหรับ
> project instance, หน้า reference ที่ deterministic และ content guard
> ใช้ได้โดยมีข้อจำกัด คำแปลไทยเป็นแบบ machine-assisted และ partial ทะเบียนยัง
> unverified และไม่มีการอ้างการทบทวนภายนอกหรือโดยมนุษย์ ส่วน kit ไม่ใช่มาตรฐาน
> ไม่ใช่การรับรอง ไม่ใช่คำแนะนำทางกฎหมาย และไม่ใช่หลักฐานของ compliance

## เหมาะกับใคร

- ทีมดิจิทัลภาครัฐ รัฐวิสาหกิจ และผู้รับจ้างที่ส่งมอบบริการสาธารณะในประเทศไทย
- Product owner, engineering lead, ทีม security และ privacy, ทีม operations,
  ผู้ประเมิน และทีม bid
- ทีมการเงิน อีคอมเมิร์ซ และโลจิสติกส์ที่ต้องใช้วินัยด้านหลักฐานแบบเดียวกัน
- ทีมที่ใช้งานอินสแตนซ์ 1.0.0 อยู่แล้วและต้องการแนวทางอัปเกรด

## release มีอะไร

- template โปรเจกต์ที่คัดลอกได้และ workflow ของ project instance ส่วนตัว
- SRAS Core ที่มี requirement ใช้งานอยู่ 70 ข้อ
- module ทางเทคนิคห้าโมดูลที่มี requirement 52 ข้อ ได้แก่ AI/GenAI,
  integration และ API, regulated data, cloud/SaaS และ on-premises
- overlay ประเทศไทยสี่ชุดที่มีส่วนเพิ่ม 45 ข้อ ได้แก่ การเงิน อีคอมเมิร์ซ
  โลจิสติกส์ และภาครัฐ
- ทะเบียนกฎระเบียบ 27 รายการ ได้แก่ประเทศไทย 12, อาเซียน 6 และสหภาพยุโรป 9
- crosswalk เชิงข้อมูล 8 ชุด รวม crosswalk NIST SP 800-218 (SSDF) 1.1 ชุดใหม่
- หน้า requirement ที่สร้างพร้อม rationale, แนวทางการประเมิน lite และ full,
  references ภายนอก และ crosswalk links
- คู่มือ operations สำหรับ adopter ครอบคลุม CI ของอินสแตนซ์ส่วนตัว การอัปเกรด
  1.x และตัวอย่าง end-to-end synthetic พร้อมแพลตฟอร์มที่รองรับ
- sentinel `Not signed` ที่ชัดเจนสำหรับ sign-off ของอินสแตนซ์ใหม่และคำเตือน
  จาก validation ที่ไม่ทำให้ล้มเหลว
- CLI ของ TypeScript สำหรับ `init`, `project validate`, `project refresh`,
  `project resolve`, `render` และ `guard`
- เอกสารภาษาอังกฤษและไทย
- หน้า reference ที่ deterministic และ content guard

## สิ่งที่เปลี่ยนตั้งแต่ 1.0.0

- หน้า requirement และหน้า crosswalk ที่สร้างแสดงเนื้อหาสำหรับการประเมินครบขึ้น
- crosswalk SSDF บันทึกแนวปฏิบัติที่ยังไม่ครอบคลุม
- `check-version` ตรวจทั้งสอง field ของ version ใน `package-lock.json`
- issue form ถาม scope, acceptance criteria, verification และ out-of-scope
  ตามที่ workflow การมีส่วนร่วมกำหนด
- `CITATION.cff` มี metadata สำหรับการอ้างอิงซอฟต์แวร์
- ไม่มี requirement ID, schema shape หรือความหมายของ gate เปลี่ยน

## สิ่งที่ไม่ได้อ้าง

- ไม่ใช่การรับรอง ไม่ใช่การรับรองระดับสถาบัน ไม่ใช่ audit attestation หรือ
  การอนุมัติจากหน่วยงานกำกับ
- ไม่ใช่คำแนะนำทางกฎหมายหรือข้อความสรุปว่าปฏิบัติตามกฎหมาย
- ไม่ใช่มาตรฐานที่เผยแพร่แล้วและผ่านการลงนามจากภายนอก
- ไม่มีผู้ทบทวนภายนอกที่เป็นมนุษย์ AI audit ไม่ได้เป็นอิสระและไม่ใช่สิ่งทดแทน
  การทบทวนภายนอก
- คำแปลไทยเป็น `translation_status: partial` และ `machine_translated: true`
  ยังไม่มีผู้ทบทวนภาษาไทยที่ระบุชื่อยืนยัน
- ทะเบียน 27 รายการเป็น `review_status: unverified`
- ข้อกังวลทางกฎหมายทั้งสี่เป็น desk research note ไม่ใช่ความเห็นทางกฎหมาย
- template เป็นแบบกลาง ไม่มีกฎจัดซื้อ การเก็บรักษา หรือการอนุมัติเฉพาะหน่วยงาน
