# Announcement template v1.2.0

**สถานะ:** final สำหรับ template release v1.2.0 เมื่อ 2026-10-29
**เวอร์ชันเนื้อหา:** SRAS 1.2.0 **release:** template release v1.2.0

นี่คือ **template release** ไม่ใช่ standard release ส่วน announcement นี้ใช้ข้อความ
ที่ตรวจสอบได้จาก repository ไม่ระบุชื่อลูกค้า โปรเจกต์จริง ผู้ทบทวน วันที่ที่ยัง
ไม่เกิดขึ้น หรือ sign-off ที่ไม่มีอยู่

## ประกาศสั้น

> โครงการ Software Delivery Assurance เผยแพร่ template release 1.2.0 ของ
> SRAS starter kit ส่วน release นี้เพิ่ม accessibility statement และ check
> accessibility อัตโนมัติสำหรับเว็บไซต์เอกสาร ปรับปรุง security policy และเพิ่ม
> AI assessment prompt ที่คัดลอกได้ ซึ่งใส่ assessment guidance และ scope ของ
> โปรเจกต์เข้าไปในตัว ส่วน kit มี requirement ที่ใช้งานอยู่ 167 ข้อ ครอบคลุม Core,
> module ทางเทคนิคห้าโมดูล และ overlay ประเทศไทยสี่ชุด พร้อมทะเบียนกฎระเบียบ 27
> รายการ, crosswalk เชิงข้อมูล 8 ชุด, CLI สำหรับ project instance, หน้า reference
> ที่ deterministic และ content guard ใช้ได้โดยมีข้อจำกัด คำแปลไทยเป็นแบบ
> machine-assisted และ partial ทะเบียนยัง unverified accessibility check เป็นการ
> ตรวจเชิงโครงสร้างเท่านั้น และไม่มีการอ้างการทบทวนจากภายนอกหรือจากมนุษย์ ไม่ใช่
> standard ไม่ใช่การรับรอง ไม่ใช่คำแนะนำทางกฎหมาย และไม่ใช่หลักฐานของ compliance

## เหมาะกับใคร

- ทีมดิจิทัลของภาครัฐไทย รัฐวิสาหกิจ และผู้รับจ้างที่ส่งมอบบริการสาธารณะ
- Product owner, engineering lead, ทีม security และ privacy, ทีม operations,
  assessor และทีม bid
- ทีม finance, e-commerce และ logistics ที่ต้องการวินัยเรื่องหลักฐานแบบเดียวกัน
- ทีมที่รัน instance 1.1.0 อยู่และต้องการเส้นทางการอัปเกรด
- ทีมที่ต้องการให้ AI assistant ร่างการประเมิน โดยไม่ยอมให้สร้างหลักฐานขึ้นมาเอง

## สิ่งที่ release มี

- template โปรเจกต์ที่คัดลอกได้ และ workflow ของ private project instance
- SRAS Core พร้อม requirement ที่ใช้งานอยู่ 70 ข้อ
- module ทางเทคนิคห้าโมดูลพร้อม requirement 52 ข้อ: AI/GenAI, integration และ API,
  regulated data, cloud/SaaS และ on-premises
- overlay ประเทศไทยสี่ชุดพร้อม delta 45 ข้อ: finance, e-commerce, logistics และ
  public sector
- ทะเบียนกฎระเบียบ 27 รายการ: ประเทศไทย 12, อาเซียน 6 และสหภาพยุโรป 9
- crosswalk เชิงข้อมูล 8 ชุด
- accessibility statement สำหรับเว็บไซต์เอกสาร พร้อมเป้าหมาย ข้อจำกัดที่ทราบ และ
  ช่องทางแจ้งปัญหา
- check axe-core อัตโนมัติกับทุกหน้าที่ build แล้ว เฉพาะ rule ระดับ A และ AA ของ
  WCAG 2.0, 2.1 และ 2.2 รันใน CI
- security policy พร้อมบันทึก advisory ของ development-only ที่มีวันที่
- template prompt และคู่มือการประเมินด้วย AI ทั้งภาษาอังกฤษและภาษาไทย
- TypeScript CLI สำหรับ `init`, `project validate`, `project refresh`,
  `project resolve`, `render` และ `guard`
- เว็บไซต์เอกสารสองภาษา อังกฤษและไทย
- หน้า reference ที่ deterministic และ content guard

## สิ่งที่เปลี่ยนตั้งแต่ 1.1.0

- เว็บไซต์เอกสารมี accessibility statement และ check อัตโนมัติ
- ปุ่มสลับ theme ที่ render จาก server มี accessible name
- `SECURITY.md` บันทึก scope เวอร์ชันที่รองรับ ความคาดหวังเรื่องการตอบกลับ และ
  advisory ของ development-only
- มี `templates/ai-assessment/prompt.md` และคู่มือ
- เว็บไซต์เอกสารถูกกันออกจาก search index
- ไม่มี requirement ID, schema shape, CLI command หรือ gate semantic ใดเปลี่ยน

## สิ่งที่ release นี้ไม่อ้าง

- ไม่ใช่การรับรอง การให้การรับรอง การรับรองการตรวจสอบ หรือการอนุมัติจากหน่วยงาน
  กำกับดูแล
- ไม่ใช่คำแนะนำทางกฎหมายหรือข้อสรุปเรื่อง compliance ทางกฎหมาย
- ไม่ใช่ standard ที่เผยแพร่และมี sign-off จากภายนอก
- ไม่มีผู้ทบทวนภายนอกที่เป็นมนุษย์เข้ามาเกี่ยวข้อง AI audit ไม่เป็นอิสระและไม่ใช่
  สิ่งทดแทนการทบทวนจากภายนอก
- คำแปลไทยมี `translation_status: partial` และ `machine_translated: true` ยังไม่มี
  ผู้ทบทวนภาษาไทยที่มีชื่อยืนยัน
- ทะเบียน 27 รายการมี `review_status: unverified`
- ข้อกังวลทางกฎหมายทั้งสี่เป็น desk research note ไม่ใช่ความเห็นทางกฎหมาย
- accessibility check ไม่ได้ทดสอบ colour contrast, การใช้คีย์บอร์ด, ลำดับ focus,
  zoom และ reflow หรือเอาต์พุตของ screen reader และไม่มีการทดสอบด้วยมือหรือ
  assistive technology
- template เป็นแบบทั่วไป ไม่ได้เข้ารหัสกฎการจัดซื้อ การเก็บบันทึก หรือการอนุมัติ
  ของหน่วยงานใดหน่วยงานหนึ่ง
