# Announcement v1.0.0 template release (draft)

**สถานะ:** draft — **ห้ามเผยแพร่ก่อน template release 1.0.0** **เตรียมเมื่อ:**
2026-10-28 สำหรับ #174 **เวอร์ชันเนื้อหาใน repository:** SRAS 0.9.0

repository ยังไม่ได้ release 1.0.0 หน้านี้เตรียมสำหรับเผยแพร่หลัง #66 สร้าง
template release และปิด milestone ต้องคงเป็น draft จนถึงตอนนั้น #66 จะลบ
draft banner และ publication checklist หลัง release มีอยู่จริง

announcement ใช้ข้อความที่ตรวจสอบได้จาก repository ไม่มีชื่อลูกค้า โปรเจกต์จริง
ผู้ทบทวน วันที่ที่ยังไม่เกิด หรือ sign-off ที่ไม่มีอยู่

## ประกาศฉบับสั้น

> โครงการ Software Delivery Assurance กำลังเตรียม template release 1.0.0 ของ
> SRAS starter kit ซึ่งเป็นวิธีแบบเปิดที่อิงหลักฐานสำหรับจัดโครงสร้าง
> การรับประกันการส่งมอบซอฟต์แวร์ kit มีข้อกำหนด active 167 ข้อ ครอบคลุม Core, technical
> module ห้าโมดูล และ overlay ภาคธุรกิจประเทศไทยสี่ชุด พร้อม register 27 รายการ
> crosswalk เชิงข้อมูลเจ็ดชุด CLI สำหรับ project instance reference pages แบบ
> deterministic และ content guard ใช้ได้โดยมีข้อจำกัด คำแปลไทยเป็น
> machine-assisted และ partial ทะเบียนยัง unverified และไม่มีการอ้างการทบทวน
> ภายนอกหรือโดยมนุษย์ kit ไม่ใช่มาตรฐาน ไม่ใช่การรับรอง ไม่ใช่คำแนะนำทาง
> กฎหมาย และไม่ใช่หลักฐานของ compliance

## สำหรับใคร

- ทีมดิจิทัลของภาครัฐ รัฐวิสาหกิจ และผู้รับจ้างที่ส่งมอบบริการสาธารณะในประเทศไทย
- product owner, engineering lead, ทีม security และ privacy, ทีม operations,
  assessor และทีมประมูล
- ทีมการเงิน อีคอมเมิร์ซ และโลจิสติกส์ที่ต้องการวินัยด้านหลักฐานแบบเดียวกัน

## release มีอะไร

- project template ที่คัดลอกได้และ workflow ของ project instance ส่วนตัว
- SRAS Core ข้อกำหนด active 70 ข้อ
- technical module ห้าโมดูล ข้อกำหนด 52 ข้อ: AI/GenAI, integration และ API,
  regulated data, cloud/SaaS และ on-premises
- overlay ภาคธุรกิจประเทศไทยสี่ชุด delta 45 ข้อ: การเงิน อีคอมเมิร์ซ โลจิสติกส์
  และภาครัฐ
- register 27 รายการ: ประเทศไทย 12, อาเซียน 6 และสหภาพยุโรป 9
- crosswalk เชิงข้อมูลเจ็ดชุดไปยังมาตรฐานภายนอก
- TypeScript CLI สำหรับ `init`, `project validate`, `project refresh`,
  `project resolve`, `render` และ `guard`
- documentation site สองภาษา English และไทย
- reference pages แบบ deterministic และ content guard

## สิ่งที่ไม่ได้อ้าง

- ไม่ใช่การรับรอง (accreditation) audit attestation หรือการอนุมัติจากหน่วยงานกำกับ
- ไม่ใช่คำแนะนำทางกฎหมายหรือข้อความสรุปว่ามี compliance กับกฎหมายใด
- ไม่ใช่มาตรฐานที่เผยแพร่พร้อม external sign-off
- ยังไม่มีผู้ทบทวนภายนอกโดยมนุษย์ AI self-review ของ v0.9.0 ไม่เป็นอิสระ
  และไม่ใช่สิ่งทดแทน external review
- คำแปลไทยเป็น `translation_status: partial` และ `machine_translated: true`
  ยังไม่มีผู้ทบทวนภาษาไทยที่มีชื่อยืนยัน
- register 27 รายการเป็น `review_status: unverified`
- ข้อกังวลทางกฎหมายสี่ข้อเป็น desk research note ไม่ใช่ legal opinion
- template เป็นแบบกลาง ไม่มีกฎจัดซื้อ การเก็บรักษา หรือการอนุมัติเฉพาะหน่วยงาน
