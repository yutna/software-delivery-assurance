# แนวคิด

หน้าในส่วนนี้อธิบายวัตถุและกฎที่อยู่เบื้องหลัง SRAS อ่านก่อนทำการประเมิน
quick start แสดงคำสั่ง หน้าเหล่านี้ธิบายสิ่งที่คำสั่งเหล่านั้นสมมติ

- [ข้อกำหนดและ criticality](requirements.md) — requirement คืออะไร gate คืออะไร
  และต้องใช้หลักฐานใด
- [Profile และ maturity](profiles.md) — ควรใช้โหมดการประเมินใด และบันทึกอะไร
- [Module และ overlay](modules-and-overlays.md) — ลักษณะผลิตภัณฑ์และส่วนเพิ่ม
  ตามภาคธุรกิจเปลี่ยน baseline อย่างไร
- [Resolution](resolution.md) — ชั้นต่าง ๆ ใช้ลำดับใด และเกิดอะไรเมื่อขัดแย้งกัน
- [Project instance](project-instance.md) — scope, assessment, evidence, claims
  และ risk อยู่ที่ใด
- [Claim และ evidence](claims-and-evidence.md) — อะไรควรกล่าวอ้างในที่สาธารณะ
  และอะไรพิสูจน์ได้
- [เครื่องมือและการตรวจสอบ](tools.md) — `validate`, `render`, `guard` และ `init`
  ปกป้องอะไร

หน้าสนับสนุนอีกสองหน้าอยู่นอกส่วนนี้

- [อภิธานศัพท์](../glossary.md) — คำศัพท์ที่ใช้ร่วมกันทั้งภาษาอังกฤษและไทย
- [Reference](../reference/index.md) — หน้าที่ generate สำหรับทุกข้อกำหนด
  overlay และทะเบียน
