# การนำร่อง

การนำร่องทดสอบไลบรารีในมุมมองของผู้ใช้ใหม่: สร้าง project instance เลือก Core
module และ overlay ประเมินข้อกำหนดที่ resolve ได้ และรัน checks โดยใช้โปรเจกต์
synthetic เท่านั้น

- **A — การเงิน:** [การนำร่องด้านการเงิน](finance.md)
- **B — ภาครัฐ:** [การนำร่องภาครัฐ](public-sector.md)

รายงานการนำร่องเป็นหลักฐานทางวิศวกรรมภายใน ไม่ใช่การประเมินลูกค้า ไม่ใช่การรับรอง
การตรวจสอบ และไม่ใช่คำแนะนำทางกฎหมาย และไม่ระบุว่าผลิตภัณฑ์เป็นไปตามข้อกำหนดทาง
กฎหมาย

## วิธีการ

การนำร่องแต่ละครั้งใช้ขั้นตอนเดียวกัน:

1. สร้าง project instance ด้วย `sras init` และ profile `full`
2. เลือก Core module ตามภาคธุรกิจ และ overlay ของภาคธุรกิจ
3. Resolve ข้อกำหนดที่เกี่ยวข้องและเปรียบเทียบกับตัวอย่าง synthetic
4. รัน `validate --all`, `render --check` และ `guard` จาก repository ของไลบรารี
5. บันทึก findings limitations และคำถามที่ยังเปิดอยู่

Findings ถูกสรุป ไม่ได้คัดลอกจากโปรเจกต์ ไม่มีชื่อลูกค้า หลักฐานจริง หรือบันทึก
ที่เป็นความลับเข้าสู่ repository นี้
